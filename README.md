# RaceCar

A configurable car physics toolkit for Unity.

## Features

- Custom engine and transmission simulation
- Pacejka-based tire forces and combined grip
- Raycast suspension
- ABS and traction control
- Automatic and manual gear shifting
- Swappable component configurations
- Editor graphs and runtime debugging tools
- Circuit, drift, drag and suspension test environments
